One image that sums up 17 November 2026's world news as a single newspaper front page — a triptych of the day's three biggest stories, laid out like a broadsheet: a bold masthead, three panels with headline, standfirst and dateline, and a bottom ticker of the day's other headlines. Entry for make.fun's "Sum up 17 November's world news in one image" bounty ($250 in USDC).

The entrypoint (`main.ts`, Node 22 stdlib only, no network, no dependencies) copies the finished 1024×1024 front-page image (`entry.png`) to the harness output directory as `entry.png`. `DOSSIER.md` documents the three stories, sources and layout decisions behind the image.

## Run it

```sh
node main.ts
```
